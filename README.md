# Assistente Virtual Jô - Documentação do Projeto

## 📌 Visão Geral

Desenvolvida por membros do Acelera, a Jô é uma assistente virtual que busca auxiliar os colaboradores da FJS a encontrar informações operacionais sobre a fundação de modo mais prático e dinâmico.

## ⚙️ Configuração

**Pré-requisitos:**
- [Ex: Node.js, Express.Js, React, Docker, ChromaDB e TypeScript.]

## Instalação para rodar localmente:

### Clone o repositório:
```bash
git clone https://github.com/Jo-Assistente/assistentevirtual.git
```
### Navegue para o diretório do projeto:
```bash
cd assistentevirtual
```
### Instale as dependências do projeto:
```bash
npm install
```
### Crie um arquivo .env e execute o projeto com Docker Compose:
```bash
docker compose up
```
### Outros comandos
```bash
ps -aux | grep runner    -- para ver se existe um runner existente
```
